네컷 포토부스 아이패드 앱 — 설치 방법
=====================================

이 폴더(PhotoBooth.swiftpm)는 '앱 프로젝트'입니다. 둘 중 한 가지 방법으로 아이패드에 설치합니다.

[방법 A] 맥이 있을 때 (가장 안정적, 추천)
 1. 맥 App Store에서 Xcode 설치 (무료)
 2. PhotoBooth.swiftpm 폴더를 더블클릭 → Xcode로 열림
 3. 왼쪽 프로젝트 → Signing & Capabilities → Team에서 내 Apple ID 선택 (없으면 Add Account)
 4. 아이패드를 USB-C로 맥에 연결 → 위쪽 기기 목록에서 아이패드 선택 → ▶ 실행
 5. 처음 한 번: 아이패드 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → 신뢰
    (아이패드에 '개발자 모드' 켜라고 나오면: 설정 → 개인정보 보호 및 보안 → 개발자 모드 → 켜기 → 재시동)
 ※ 무료 Apple ID는 7일마다 맥에 연결해서 ▶ 한 번 더 눌러 줘야 합니다. (유료 개발자 계정 연 129,000원이면 1년)

[방법 B] 맥이 없을 때: 아이패드의 Swift Playgrounds 앱
 1. App Store에서 'Swift Playgrounds' 설치
 2. 이 zip 파일을 '파일' 앱에서 풀고 PhotoBooth.swiftpm 을 누르면 Swift Playgrounds로 열림
 3. 오른쪽 위 ▶ (앱 실행) → 전체 화면으로 포토부스가 뜸
 ※ 예전에 Playgrounds에서 'Failed to launch'가 났던 아이패드라면, Playgrounds를 최신으로 업데이트하거나
    다른 아이패드(에어)에서 해 보세요. 그래도 안 되면 방법 A를 써야 합니다.

[처음 실행하면]
 1. 카메라 허용
 2. 왼쪽 위 모서리 5번 → 비밀번호 0000 → 관리자 설정 → '프린터 선택' → Canon SELPHY CP1300 고르기
    (한 번만 고르면 계속 기억합니다)
 3. 이후에는 인쇄하기를 누르면 인쇄 창 없이 바로 SELPHY로 나갑니다.

[SELPHY CP1300 설정 — 안정적으로 쓰려면]
 - Wi-Fi 연결은 '공유기(접속 포인트)를 통한 연결'로: 아이패드와 같은 공유기에 연결
   (프린터와 직접 연결하는 방식은 아이패드 인터넷이 끊기고 자주 끊어짐)
 - 프린터의 자동 꺼짐(Auto Power Down)이 있으면 끄기 → 행사 중 프린터가 잠들어 인쇄가 안 되는 일 방지
 - 펌웨어가 최신인지 확인 (Canon 지원 사이트)
 - 프린터를 공유기·아이패드 가까이, 부스 뒤는 벽에서 15cm 띄우기

[앱이 하는 일]
 - 포토부스 화면을 앱 안에 넣어 둠 → 인터넷이 없어도 동작, Safari 탭이 꺼지거나 새로고침되는 문제 없음
 - 인쇄: 저장해 둔 SELPHY에 먼저 연결되는지 확인 → 엽서 용지를 직접 지정해서 인쇄 창 없이 전송
   (프린터가 꺼져 있으면 바로 알려 줘서 다시 누르면 됨)
 - 화면 꺼짐 방지, 무음 모드여도 소리 나옴, 상태 바 숨김
