네컷 포토부스 아이패드 앱 v1.11 — 처음부터 설치하기 (Xcode)
=============================================================

이 zip 하나에 앱 전체(앱 코드 + 화면 + 프레임·스티커·글꼴·목소리)가 다 들어 있어요.
예전 업데이트 파일을 따로 넣을 필요 없어요.

[설치]
 1. zip을 풀면 나오는 PhotoBooth.swiftpm 폴더를 원하는 곳(예: 문서)에 둡니다. 폴더 이름은 바꾸지 마세요.
 2. PhotoBooth.swiftpm 을 더블클릭 → Xcode로 열림 (처음엔 왼쪽 위 진행 표시가 끝날 때까지 1~2분 기다리기)
 3. 왼쪽 맨 위 'PhotoBooth' → Signing & Capabilities → Team에서 내 Apple ID(Personal Team) 선택
    · 'Bundle Identifier가 이미 쓰인다'는 오류가 나면 com.strangeenglish.photobooth 끝에 숫자를 붙여 바꾸기
      (예: com.strangeenglish.photobooth2)
 4. 아이패드를 USB-C로 맥에 연결 → Xcode 위쪽 기기 목록에서 아이패드 선택 → ▶ 실행
 5. 처음 한 번만:
    · 아이패드 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → 신뢰
    · '개발자 모드'를 켜라고 나오면: 설정 → 개인정보 보호 및 보안 → 개발자 모드 켜기 → 재시동
 ※ 무료 Apple ID는 7일마다 맥에 연결해 ▶ 한 번 더 눌러야 해요 (유료 개발자 계정이면 1년)

[빨간 오류가 날 때]
 · Package.swift 의 .localNetwork(...) 줄에서 오류가 나면: 그 줄과 바로 위 줄 끝의 쉼표(,)를 지우고 다시 ▶
   (셀피 찾기 허용 창만 안 뜨고 나머지는 그대로 동작)
 · 그 밖의 오류는 오류 문장을 그대로 복사해서 보내 주세요.
 · 이상하게 안 될 때: Xcode 메뉴 Product → Clean Build Folder (⇧⌘K) 후 다시 ▶

[처음 실행하면]
 1. '카메라' 허용, '로컬 네트워크' 허용 (셀피 인쇄·QR 받기에 꼭 필요)
    실수로 거부했으면: 아이패드 설정 → PhotoBooth → 카메라 / 로컬 네트워크 켜기
 2. 시작 점검 화면이 자동으로 돌아감 → 테스트 인쇄까지 해 보고 문제 있으면 [보고서]를 보내 주세요
 3. 관리자 설정: 화면 왼쪽 위 모서리 5번 → 비밀번호 0000 (설정에서 꼭 바꾸기)

[관리자 설정에서 확인할 것]
 · 인쇄 방법: '셀피 바로 (추천)' — Canon PRINT 앱과 같은 방식으로 셀피에 직접 보냄
   (셀피와 아이패드가 같은 공유기 Wi-Fi이거나, 아이패드가 셀피 Wi-Fi에 직접 연결)
 · 인쇄 전 취소 시간: 기본 5초 (실수로 누른 인쇄를 취소할 수 있음)
 · QR 받는 방법:
   - 같은 와이파이: 손님 휴대폰이 같은 와이파이여야 함 → 와이파이 이름·비밀번호를 적으면 와이파이 연결 QR도 나옴
   - 인터넷 링크: 휴대폰 데이터로도 받음 (사진·GIF를 72시간 임시 보관 후 자동 삭제). 갤럭시 손님이 많으면 추천
 · 사진 아래 글자(행사 이름), 프레임, 포즈 목소리·행사별 포즈 묶음, 내 프레임(Canva PNG) 추가

[이 폴더에 든 것]
 · *.swift — 아이패드 앱 코드 (카메라 화면, 셀피 직접 인쇄, QR 받기 서버)
 · Package.swift — 앱 설정 (이름, 권한)
 · Web/ — 포토부스 화면 전체 (index.html, 프레임·스티커·글꼴·목소리·얼굴 인식 파일)
 · 원본 백업: https://github.com/Sehunyi/photobooth (파일이 또 사라지면 여기서도 받을 수 있어요)
